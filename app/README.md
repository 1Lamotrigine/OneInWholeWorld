# Жизнь в Эларионе

Браузерный симулятор одной случайной жизни. В 1230 году Эларион разыгрывает расу, поселение и происхождение. Затем годы меняют персонажа, его близких и мир. Решения игрока открывают одни возможности и закрывают другие. После смерти в архиве остаётся летопись с причинами, вехами и итогом жизни.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
cd app
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для проверки статического экспорта выполните `npm run build && npm run preview` и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Содержимое `out/` можно раздавать обычным HTTP-сервером с поддержкой индексных файлов в каталогах. Используйте один и тот же адрес и порт, чтобы видеть один архив IndexedDB. На телефоне при открытии приложения с другого устройства используйте HTTPS, чтобы браузер предоставил доступ к локальному хранилищу и блокировкам.

## Управление

- **Начать жизнь** разыгрывает персонажа. **Прожить жизнь** запускает течение времени.
- При рождении можно дождаться раскрытия или пропустить прокрутку. Затем нужно подтвердить один из пятнадцати жизненных путей. Путь сохраняется на всю жизнь.
- **Народы Элариона** на главной странице показывают описания восьми рас, диапазоны жизни, возрастные этапы и начальные особенности.
- **Карта мира** рядом с иконкой персонажа показывает границы, лор и 42 поселения. Масштаб меняется колесом или кнопками, карта двигается перетаскиванием или стрелками. У каждого поддерживаемого пути есть профильное учреждение. С юности оно даёт дополнительный опыт пути и конкретные годовые прибавки к знаниям, репутации, доходу или навыкам. Поручения роли проверяются чаще. Значения с учётом расы показаны на карте и в панели пути.
- **Вехи пути** открываются по мере накопления опыта. У каждой роли есть три важные развилки. Выбор создаёт долгосрочные программы в своей стране, а поздние вехи затрагивают соседей. Через четыре года приходят решения о пересмотре программы.
- **Сверхъестественный мир**: 32 новые встречи с драконами, титанами, фейскими дворами, василисками, некромантами и живыми башнями; собственные сюжеты восьми рас и пятнадцати ролей. Шесть отложенных развязок возвращают цену магических договоров, восемь чудес сопровождают разные возрасты. При обычном подборе после двух повседневных историй выбирается фэнтезийная. Отложенные последствия, срочные угрозы и вехи роли сохраняют приоритет. Повседневность остаётся контрастом.
- **Магические печати**: проклятие Бездны, долг феям, драконья клятва, лунное превращение, руны титана и память мёртвых ежегодно меняют характеристики, пока не истечёт срок или игрок не разорвёт договор. Эффекты и срок показаны отдельно. У рискованных решений указан шанс успеха по способностям; неудачи могут ранить. Дети действуют вместе со взрослыми, а государственные катастрофы требуют зрелости.
- **Катастрофы**: небесные разломы, армии нежити, Дикая Охота и драконы меняют показатели страны, вызывают срочные решения и отображаются эффектами поверх сцены. Успешное вмешательство заканчивает местную угрозу. Защитные руны снижают вероятность новых магических бедствий, запретные исследования её повышают. Фэнтезийные вести составляют большую часть фоновых сообщений.
- **Войны и границы**: ежегодные кампании используют осады, удары по снабжению и обходы. Экономика, еда, безопасность и союзники меняют шансы. Захват городской территории перекрашивает карту; потеря последней территории лишает государство независимости. Двенадцатилетние оборонительные альянсы усиливают снабжение. Исторические названия областей и городов сохраняются. Мирные договоры останавливают завоевания, но не возвращают автоматически прежние границы.
- **Дилеммы**: четыре новых встречи имеют скрытую честную или преступную личность с равными шансами, определённую по seed до выбора. И помощь, и отказ дают разные отложенные последствия через три года. У попутчика также есть риск передачи адреса ворам. Перезагрузка не меняет личность. Решения об общих запасах и тактике фронта меняют разные показатели с явной ценой. Решения не выдаются до минимального возраста понимания, а отложенные последствия повторно проверяют возраст.
- **Карьерные условия города**: в подходящей среде опыт пути растёт быстрее и есть профильные прибавки. Без поддержки растут только 0,35 базового опыта за год вместо 1,6, теряются 0,5 репутации, 0,8 монеты и 0,35 счастья. Числа делятся на расовый коэффициент темпа. Поручения проверяются раз в 8 вместо 3 базовых лет. Со зрелости годовой риск карьерного провала составляет 0,8%, при низкой безопасности 2,5%, при войне 6% (также с учётом темпа расы); возможны потеря работы, репутации и опасное ранение. Условия показаны до переезда и в раскрытой панели пути.
- **Влияние на мир** открывает действия вашего пути. Для объявления войны нужна высокая репутация и соседняя страна. Перемирие завершает войну по обе стороны границы. **Вести из Элариона** показывают события и смены власти по всему материку. Блок **Дела, меняющие страну** показывает основателя, срок и последствия программы. Долговременные условия меняют показатели страны и веса будущих событий, включая войны, эпидемии, восстания и открытия.
- **Пауза** останавливает время. Клавиша пробела переключает паузу вне интерактивных элементов. Скорости 1×, 2×, 5× и 10× меняют длительность игрового года. Годы долгоживущих рас проходят быстрее.
- **До решения** продвигает симуляцию до ближайшего обязательного выбора или конца жизни. Важный выбор останавливает время. После решения можно продолжить или перейти к следующему выбору.
- **Авторежим** принимает решения во время хода времени с учётом приоритета и черт. Приоритет также меняет годовые эффекты и вероятность встречи тематических событий.
- **Язык** переключается прямо в шапке: рядом со списком отображается флаг выбранного языка. Поддерживаются русский, английский, немецкий, испанский и итальянский. Локальные словари охватывают интерфейс, мир и события. Выбор языка сохраняется на устройстве. Переводы подготовлены машинным переводом с ручной правкой основных терминов.
- **Сохранения** открывают архив. JSON можно экспортировать, импортировать как отдельную жизнь и удалить из архива. Итоговая карточка доступна в PNG.

## Устройство

| Каталог | Назначение |
| --- | --- |
| `src/app/` | Старт, игровой экран, архив, общие стили и статические маршруты |
| `src/components/` | Адаптивные панели, доступное управление временем, сцены и летопись |
| `src/game/content/` | Восемь рас, двенадцать стран, восемь происхождений, 25 профессий, 337 событий, в том числе 216 с выбором |
| `src/game/engine/` | Генерация, правила года, события, решения, мир и смертность |
| `src/stores/`, `src/application/` | Сессия Zustand, часы, запуск сохранения и восстановление |
| `src/db/` | PGlite в Web Worker, IndexedDB, миграции, транзакции и проверка формата |
| `public/art/`, `scripts/draw-art.py` | Локальные SVG-сцены и их генератор |
| `src/game/tests/`, `e2e/` | Тесты движка, репозитория и браузерных сценариев |

Порядок тика фиксирован. Сначала меняются возраст и этап жизни, затем потребности, занятость, близкие и статус. После обновления регионов обрабатываются здоровье, отложенные последствия и подходящее событие. Обязательное решение завершает год после выбора и проверки смертности. Состояние PRNG сохраняется рядом с состоянием мира. Старые жизни версий 1, 2, 3, 4 и 5 открываются с прежней летописью. Для прежнего выбранного пути опыт восстанавливается по возрасту. Сохранения версии 5 сохраняют политический контроль, альянсы и программы, получая пустой набор личных магических печатей. В более старых сохранениях политический контроль начинается с исходных границ; прежние программы версии 4 сохраняются. Невозможное по возрасту ожидающее решение снимается без удаления летописи. Новые страны добавляются при миграции, а пол персонажа восстанавливается по культурному набору имён. Для неизвестного имени показывается «Не указан».

PGlite держит снимок и записи летописи в отдельных таблицах и пишет их в одной транзакции. Worker разделяет соединение между вкладками. Запись проверяет исходную ревизию, чтобы устаревшая вкладка не перезаписала новую. При перезагрузке незавершённая запись повторяется из журнала вкладки. При проблемах с хранилищем игру можно продолжить с ручным экспортом. См. [документацию PGlite о Multi-tab Worker](https://pglite.dev/docs/multi-tab-worker).

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

При установленном Google Chrome можно запустить `ELARION_BROWSER=chrome npm run test:e2e` без отдельной установки Chromium. По умолчанию Playwright обслуживает статический экспорт локально.

## Границы MVP

- Сцены и портреты используют временные SVG-композиции на пиксельной сетке. Новые страны используют общие фоны по типу местности.
- Близкие моделируются компактными записями, регионы используют агрегированные показатели. Детальный быт NPC, династии и долговременная демография оставлены для расширения.
- Темп, экономика и частота редких карьер заданы стартовым балансом. Полная офлайн-установка и предварительное кеширование ресурсов требуют PWA-слоя.
