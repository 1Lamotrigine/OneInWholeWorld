# Жизнь в Эларионе

Браузерный симулятор одной случайной жизни. В 1230 году Эларион разыгрывает расу, поселение и происхождение. Затем годы меняют персонажа, его близких и мир. Решения игрока открывают одни возможности и закрывают другие. После смерти в архиве остаётся летопись с причинами, вехами и итогом жизни.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
cd app
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для проверки статического экспорта выполните `npm run build && npm run preview` и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Содержимое `out/` можно раздавать обычным HTTP-сервером с поддержкой индексных файлов в каталогах. Используйте один и тот же адрес и порт, чтобы видеть один архив IndexedDB. На телефоне при открытии приложения с другого устройства используйте HTTPS, чтобы браузер предоставил доступ к локальному хранилищу и блокировкам.

## Управление

- **Начать жизнь** разыгрывает персонажа. **Прожить жизнь** запускает течение времени.
- При рождении можно дождаться раскрытия или пропустить прокрутку. Затем нужно подтвердить один из семи жизненных путей. Путь сохраняется на всю жизнь.
- **Карта мира** рядом с иконкой персонажа показывает границы, лор и 18 поселений. Масштаб меняется колесом или кнопками, карта двигается перетаскиванием или стрелками. Откройте подходящее поселение, чтобы проверить условия переезда.
- **Влияние на мир** открывает действия вашего пути. Для объявления войны нужна высокая репутация и соседняя страна. Перемирие завершает войну по обе стороны границы. **Вести из Элариона** показывают события и смены власти по всему материку.
- **Пауза** останавливает время. Клавиша пробела переключает паузу вне интерактивных элементов. Скорости 1×, 2×, 5× и 10× меняют длительность игрового года. Годы долгоживущих рас проходят быстрее.
- **До решения** продвигает симуляцию до ближайшего обязательного выбора или конца жизни. Важный выбор останавливает время. После решения можно продолжить или перейти к следующему выбору.
- **Авторежим** принимает решения во время хода времени с учётом приоритета и черт. Приоритет также меняет годовые эффекты и вероятность встречи тематических событий.
- **Сохранения** открывают архив. JSON можно экспортировать, импортировать как отдельную жизнь и удалить из архива. Итоговая карточка доступна в PNG.

## Устройство

| Каталог | Назначение |
| --- | --- |
| `src/app/` | Старт, игровой экран, архив, общие стили и статические маршруты |
| `src/components/` | Адаптивные панели, доступное управление временем, сцены и летопись |
| `src/game/content/` | Пять рас, шесть регионов, восемь происхождений, 25 профессий, 164 события, в том числе 81 с выбором |
| `src/game/engine/` | Генерация, правила года, события, решения, мир и смертность |
| `src/stores/`, `src/application/` | Сессия Zustand, часы, запуск сохранения и восстановление |
| `src/db/` | PGlite в Web Worker, IndexedDB, миграции, транзакции и проверка формата |
| `public/art/`, `scripts/draw-art.py` | Локальные SVG-сцены и их генератор |
| `src/game/tests/`, `e2e/` | Тесты движка, репозитория и браузерных сценариев |

Порядок тика фиксирован. Сначала меняются возраст и этап жизни, затем потребности, занятость, близкие и статус. После обновления регионов обрабатываются здоровье, отложенные последствия и подходящее событие. Обязательное решение завершает год после выбора и проверки смертности. Состояние PRNG сохраняется рядом с состоянием мира. Старые жизни версии 1 открываются с прежней летописью и могут выбрать путь при продолжении.

PGlite держит снимок и записи летописи в отдельных таблицах и пишет их в одной транзакции. Worker разделяет соединение между вкладками. Запись проверяет исходную ревизию, чтобы устаревшая вкладка не перезаписала новую. При перезагрузке незавершённая запись повторяется из журнала вкладки. При проблемах с хранилищем игру можно продолжить с ручным экспортом. См. [документацию PGlite о Multi-tab Worker](https://pglite.dev/docs/multi-tab-worker).

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

При установленном Google Chrome можно запустить `ELARION_BROWSER=chrome npm run test:e2e` без отдельной установки Chromium. По умолчанию Playwright обслуживает статический экспорт локально.

## Границы MVP

- Сцены и портреты используют временные SVG-композиции на пиксельной сетке.
- Близкие моделируются компактными записями, регионы используют агрегированные показатели. Детальный быт NPC, династии и долговременная демография оставлены для расширения.
- Темп, экономика и частота редких карьер заданы стартовым балансом. Полная офлайн-установка и предварительное кеширование ресурсов требуют PWA-слоя.
